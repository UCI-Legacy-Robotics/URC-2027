# GUI frontend

```bash
pnpm install     # also installs git hooks
pnpm dev         # Electron app, control mode
pnpm dev:web     # browser, viewer mode (localhost:5174)
pnpm storybook   # build widgets against fake data (localhost:6006)
pnpm build       # production build; static UI in out/renderer/
```
